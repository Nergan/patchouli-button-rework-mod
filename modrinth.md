Книга-сборник чужих книг Patchouli для Minecraft 1.21.1. Ставится один загрузчик, не оба сразу.

## NeoForge

Обязательно: `patchoulibutton-neoforge-1.21.1-1.0.0.jar`, Kotlin for Forge 5.8.0 и Patchouli `1.21.1-93-neoforge`.

## Fabric

Обязательно: `patchoulibutton-fabric-1.21.1-1.0.0.jar`, Fabric API `0.116.17+1.21.1`, Fabric Language Kotlin `1.13.2+kotlin.2.1.20`, Patchouli `1.21.1-93-fabric` и Cloth Config `15.0.140`. Fiber уже лежит внутри jar Patchouli, отдельно его ставить не нужно. Строка «нужен fabric 0.100.3» означает jar Fabric API, не Fabric Loader. Необязательно: Mod Menu 11.0.4, ему нужен Text Placeholder API `2.4.2+1.21`.

A compendium of other mods' Patchouli books for Minecraft 1.21.1. Install one loader, not both.

## NeoForge

Required: `patchoulibutton-neoforge-1.21.1-1.0.0.jar`, Kotlin for Forge 5.8.0, and Patchouli `1.21.1-93-neoforge`.

## Fabric

Required: `patchoulibutton-fabric-1.21.1-1.0.0.jar`, Fabric API `0.116.17+1.21.1`, Fabric Language Kotlin `1.13.2+kotlin.2.1.20`, Patchouli `1.21.1-93-fabric`, and Cloth Config `15.0.140`. Fiber is already inside the Patchouli jar, so do not install it again. A line that says "requires fabric 0.100.3" means the Fabric API jar, not Fabric Loader. Optional: Mod Menu 11.0.4, which needs Text Placeholder API `2.4.2+1.21`.
